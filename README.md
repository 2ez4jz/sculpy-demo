# Sculpy · SCULP Studio

单页概念 Demo，沿用 SCULP Studio 的象牙白、炭黑、衬线字体与留白。以温暖回应为主，工作记录自然地留在旁边。

## 使用

选择化妆师与日期，语音或文字告诉 Sculpy 今天的工作。工作场次自动保存，右侧仅显示所选化妆师在所选日期的记录；按需展开查看原文或修改姓名、项目、偏好。仅表达疲惫或心情时不会新增工作记录。

浏览器原生语音转写支持中文 / English，首次需要麦克风权限。可选系统语音朗读，提供示例台词及投屏模式。

## 演示边界

语音转写真实使用浏览器 SpeechRecognition 服务。整理与情绪回复使用预设规则，尚未接 GPT、公司数据库、员工登录或图片识别。化妆师选择是演示身份切换。记录仅保存在当前浏览器 localStorage，不同步设备。请使用虚构资料；浏览器供应商可能处理语音。

每次工作输入是一条独立场次，不会自动合并同名客户。记录归属所选化妆师和日期。婚礼未提供年份时规则按当年推断；可查看原文，真实系统接入前需完善日期确认。

## 开发

零依赖静态网页。`python3 -m http.server 8000`，访问 `http://localhost:8000`。

GitHub Pages 使用 main 分支 / 根目录。`node --check app.js`、`node --check parser.js`、`node verify.cjs`。

未来 GPT 接入需服务端代理，不能将 API key 放到公开仓库或网页前端。
