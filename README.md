# Sculpy · SCULP Studio

一个发布会用的单页概念 Demo，视觉沿用 SCULP Studio 的象牙白、炭黑、衬线字体与留白。

## 已实现

- 浏览器原生语音转写：中文 / English，可显示实时文字；首次使用需要麦克风权限和 HTTPS（localhost 也可）。
- 文字输入，婚礼试妆 / 活动造型示例台词。
- 演示规则抽取姓名、项目、日期、偏好、潜在需求，生成可修改的记录卡；原始输入保留。
- 人工确认后保存到当前浏览器 localStorage，支持历史查看、修改、重置。
- 可选系统语音朗读、桌面投屏模式、移动端排版。

## 明确的演示边界

语音转写真实调用浏览器 SpeechRecognition 服务；**没有接入 GPT API、图片理解、公司数据库或员工权限**。整理与回复使用透明的演示规则，不是通用 AI。未识别内容仍保留在原始输入里。记录仅在本机，不同步设备。请使用虚构客户资料；浏览器语音供应商可能处理语音。

婚礼未说年份时按当前年补齐并提示确认。服务日期默认今天，提及“昨天”则按昨天；其余日期应人工修正。每段输入是一条独立工作记录，不会自动合并重名客户。

## 现场使用

优先使用桌面 Chrome，在会前允许麦克风并实测中文夹英文人名。点击麦克风说话 → 再点停止 → 检查文字 → 整理记录 → 确认保存。

> Sculpy，今天给 Amy 做了 bridal trial，她喜欢自然一点的妆，眼妆不要太重。婚礼是 2026 年 11 月 8 号，她妈妈可能也要做造型。

现场网络 / 语音服务失败时点示例文字，继续相同流程。

## 开发与发布

零依赖静态网页。运行 `python3 -m http.server 8000`，访问 `http://localhost:8000`。

GitHub Pages：Settings → Pages → Deploy from a branch → main → /(root)。所有文件使用相对路径，可直接部署到仓库子路径。

检查：`node --check app.js`、`node --check parser.js`、`node verify.cjs`。

未来接 GPT 时需要服务端代理保管 API key，不能把密钥放在 GitHub Pages 前端或公开仓库中。
